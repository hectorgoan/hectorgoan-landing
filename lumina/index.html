Install in a minute.

Lumina isn’t notarized by Apple, so macOS asks you once to allow it.

  1. 1 Download and unzip Get Lumina.zip from the latest release and open it.
  2. 2 Move it to Applications Drag Lumina.app into your Applications folder, then open it.
  3. 3 Click Open Anyway The first time, macOS says it can’t check the app. Scroll to Security and click Open Anyway next to Lumina. System Settings › Privacy & Security

You only do this once. Lumina checks for updates when it opens and every six hours, and installs them in place.
